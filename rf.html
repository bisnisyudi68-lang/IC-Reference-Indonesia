Komponen RF Umum Smartphone

IC / Jalur Fungsi Jika Rusak
PA (Power Amplifier) Penguat sinyal jaringan Sinyal lemah / hilang total
RF Transceiver Proses kirim & terima sinyal No service
Switch Antenna Pilih jalur frekuensi Sinyal 1 bar / naik turun
Filter RF Saring frekuensi tertentu Tidak bisa 4G / 5G
IC Baseband Kontrol komunikasi jaringan IMEI null / baseband unknown
Clock RF Referensi frekuensi Sinyal tidak stabil
IC WiFi/Bluetooth Koneksi wireless WiFi grey / tidak aktif
SIM Interface Deteksi kartu SIM No SIM / insert SIM

🔎 Analisa Cepat No Signal

✔ IMEI ada tapi no service → cek PA / antenna switch

✔ IMEI null → cek CPU / baseband

✔ Sinyal 1 bar → cek filter & antenna

✔ WiFi grey → cek tegangan 3.3V jalur RF
