🧭 Mode Jalur Tracker

🔴 Mode Pasif (HP Tidak Start)

1️⃣ Ukur VBAT di konektor
2️⃣ Cek jalur ke PMIC
3️⃣ Cek short utama (inject 4V)
4️⃣ Ukur output 1.8V & 3.3V
5️⃣ Jika Vcore tidak keluar → PMIC rusak

🟢 Mode Aktif (Ada Arus Tapi Tidak Normal)

1️⃣ Perhatikan arus awal
2️⃣ 0.02A → CPU / clock
3️⃣ 0.40A → Storage
4️⃣ 0.80A reboot → Firmware
5️⃣ Cek jalur data & baseband
