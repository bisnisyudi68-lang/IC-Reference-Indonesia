🧭 Jalur Tracker Teknisi HP

📌 Tracing Jalur VBAT (HP Mati Total)

1️⃣ Ukur VBAT di konektor baterai
2️⃣ Jika ada → cek ke PMIC input
3️⃣ Jika hilang → cek coil utama
4️⃣ Jika short → inject 4V
5️⃣ Rasakan panas IC

⚡ Tracing 1.8V Hilang

1️⃣ Cek output LDO PMIC
2️⃣ Jika 0V → cek enable signal
3️⃣ Jika enable ada → PMIC rusak
4️⃣ Jika short → lepas kapasitor satu per satu

📶 Tracing No Signal

1️⃣ Cek IMEI
2️⃣ Cek baseband
3️⃣ Ukur tegangan PA
4️⃣ Cek antenna switch
5️⃣ Rehot RF IC

💾 Tracing eMMC Tidak Detect

1️⃣ Ukur VCC 2.8V
2️⃣ Ukur VCCQ 1.8V
3️⃣ Cek CLK & CMD
4️⃣ Jika arus 0.40A → bad block
5️⃣ Test via ISP
