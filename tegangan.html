⚡ Database Jalur Tegangan PMIC

Tegangan Umum Smartphone

Jalur Tegangan Fungsi Jika Hilang
VBAT 3.7 – 4.2V Supply utama baterai HP mati total
VPH_PWR 3.8V Input utama ke PMIC Tidak bisa start
VREG_L1 1.8V Supply CPU IO No boot / stuck logo
VREG_L2 3.3V Supply RF / Peripheral No signal / WiFi mati
VDD_CPU 0.8 – 1.2V Core CPU CPU tidak kerja
VDD_RAM 1.1 – 1.2V Supply RAM Bootloop / restart
VDD_UFS 1.2V / 2.8V Supply IC UFS Tidak detect storage
VIO_CAM 1.8V Supply kamera Kamera error
VREG_SIM 1.8V / 3V Supply SIM No SIM detected
VDD_WIFI 3.3V Supply IC WiFi WiFi grey

⚡ Analisa Cepat

Jika 1.8V hilang → Cek regulator LDO PMIC

Jika 3.3V drop → Cek short di jalur peripheral

Jika VDD_CPU tidak keluar → PMIC rusak / CPU short

Jika VBAT normal tapi tidak start → Cek power key / SIO
