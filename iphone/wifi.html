📡 iPhone WiFi Grey / Tidak Aktif

Gejala Umum

Kondisi Kemungkinan Penyebab
WiFi tombol abu-abu IC WiFi rusak / solder retak
Bluetooth tidak aktif IC combo WiFi/BT rusak
WiFi hilang setelah jatuh Board flex retak
WiFi hilang setelah panas Cold solder IC WiFi

Langkah Diagnosa

  1. Reset network setting
  2. Restore iOS (untuk pastikan bukan software)
  3. Ukur tegangan PP3V0_WLAN
  4. Periksa IC WiFi dengan thermal
  5. Reflow atau reball IC WiFi

Level Senior

  • Jika WiFi + Bluetooth mati bersamaan → 90% IC WiFi
  • Jika hanya WiFi mati → cek jalur antenna
  • Perhatikan board sandwich (iPhone X–11)
  • Gunakan microscope untuk cek solder crack
