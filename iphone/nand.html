Error 4013 / 4014 / Storage Issue

Error 4013

Biasanya karena NAND tidak stabil, jalur CPU ke NAND putus, atau solder retak.

  • Cek resistansi jalur PP1V8_NAND
  • Reheat ringan NAND
  • Reball jika perlu

Error 4014

Sering disebabkan jalur komunikasi CPU - NAND bermasalah.

  • Cek jalur data NAND
  • Cek short di PP3V0_NAND
  • Pastikan tidak ada korosi
