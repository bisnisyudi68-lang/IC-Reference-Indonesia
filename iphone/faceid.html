📷 iPhone Face ID Error

Komponen Face ID (TrueDepth)

Komponen Fungsi
Flood Illuminator Pencahayaan wajah
Dot Projector Proyeksi titik wajah
Infrared Camera Deteksi pola wajah
ALS / Proximity Sensor jarak

Kondisi Umum

Error Muncul Kemungkinan
Face ID Not Available Flood Illuminator mati
Move iPhone Lower/Higher Infrared Camera rusak
Cannot Activate Face ID Dot Projector error
Setelah Ganti LCD Flex sensor tidak terpasang

Langkah Diagnosa

  1. Cek kamera depan normal?
  2. Cek proximity sensor berfungsi?
  3. Periksa flex TrueDepth
  4. Ukur tegangan 1.8V sensor line
  5. Jangan sembarang ganti Dot Projector (pairing!)

Catatan Penting

Face ID memiliki sistem pairing hardware. Jika Dot Projector rusak dan diganti tanpa alat khusus, Face ID tidak akan aktif kembali.
