🔌 iPhone Tidak Charging (X ke atas)

Gejala Umum

Gejala Kemungkinan
Tidak muncul icon charging IC Charging / Tristar rusak
Muncul tapi % tidak naik Baterai rusak / Fuel gauge
HP mati saat dicolok Short PP_VDD_MAIN
Tidak terdeteksi di PC IC USB / Tristar

Langkah Diagnosa

  1. Cek port lightning kotor atau tidak
  2. Ukur tegangan PP_BATT_VCC
  3. Cek jalur ke IC charging
  4. Ukur arus saat colok charger
  5. Jika 0.00A → cek Tristar

Level Senior

  • Inject 4V untuk cek short jalur utama
  • Cek diode mode pada line USB
  • Jika sering tidak detect PC → IC USB rusak
  • Hati-hati jalur bawah CPU (multi-layer board)
