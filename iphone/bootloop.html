🔄 iPhone Bootloop / Restart 3 Menit

Jenis Bootloop

Kondisi Kemungkinan Penyebab
Restart tiap 3 menit Sensor / EEPROM audio rusak
Stuck Logo Apple NAND / iOS corrupt
Boot lalu mati PMIC drop / baterai rusak
Boot saat panas saja Cold solder CPU / NAND

Restart 3 Menit (Kasus Umum X–11)

  1. Cek mic bawah (audio IC line)
  2. Cek proximity sensor
  3. Cek flex ear speaker
  4. Disconnect satu per satu sensor

Stuck Logo Apple

  1. Masuk Recovery Mode
  2. Restore via iTunes
  3. Jika gagal → kemungkinan NAND issue
  4. Cek arus 0.05–0.10A stuck

Level Senior

  • Gunakan 3uTools untuk log error
  • Periksa panic log di analytics data
  • Jika ada error “mic1” → audio line putus
  • Jika ada error “thermal” → sensor suhu rusak
