📶 iPhone No Signal / Searching

Step Diagnosa Awal

  1. Masuk Settings → General → About
  2. Cek IMEI ada atau null
  3. Cek Baseband firmware muncul atau tidak
  4. Coba reset network
  5. Test SIM lain

Analisa Berdasarkan Kondisi

Kondisi Kemungkinan Kerusakan
IMEI Null Baseband CPU rusak / jalur putus
No Baseband PMU_RF rusak / short jalur baseband
Searching terus PA_RF rusak / antena putus
No Service setelah jatuh IC Baseband retak (flex board)
Sinyal hilang panas IC RF overheating / solder retak

Langkah Level Senior

  1. Ukur tegangan VDD_RF
  2. Cek clock 26MHz
  3. Reball CPU Baseband (jika perlu)
  4. Reflow PMU_RF
  5. Cek jalur antena ke PA_RF
